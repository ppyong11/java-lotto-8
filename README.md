# java-lotto-precourse
### 프로그램 개요
이 프로그램은 사용자에게 로또 구입 금액과 당첨 번호 6개, 보너스 번호 1개 총 7개의 번호를 받아 랜덤으로 발행된 로또와 비교한 후, 당첨 결과를 계산하고 수익률을 알려준다. 입력 값이 형식에 맞지 않거나 잘못된 경우 에러 메시지를 출력하고 해당 입력을 다시 받는다.
### 기능 요구 사항
1. 로또 번호의 숫자 범위는 1~45까지이다.
2. 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.
3. 당첨 번호 추첨 시 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.
4. 당첨은 1등부터 5등까지 있다. 당첨 기준과 금액은 아래와 같다.
   - 1등: 6개 번호 일치 / 2,000,000,000원
   - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
   - 3등: 5개 번호 일치 / 1,500,000원
   - 4등: 4개 번호 일치 / 50,000원
   - 5등: 3개 번호 일치 / 5,000원로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행해야 한다.

5. 로또 1장의 가격은 1,000원이다. 
6. 당첨 번호와 보너스 번호를 입력받는다. 
7. 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임을 종료한다. 
8. 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
   - Exception이 아닌 IllegalArgumentException, IllegalStateException 등과 같은 명확한 유형을 처리한다.
### 구현할 기능
- 로또 구입 금액 입력
  - 금액을 입력받는다.
  - 금액은 1,000원 단위로만 입력 가능하다.
  - 1,000원으로 나누어 떨어지지 않는 경우 예외 처리한다.
  - 숫자가 아닌 값 입력 시 예외 처리한다.
- 당첨 번호 입력(6개)
  - 쉼표(,)로 구분된 6개의 번호를 입력받는다.
  - 번호는 1부터 45 사이여야 한다. 
  - 번호가 중복되거나 숫자가 아닌 값, 개수 불일치, 잘못된 구분자 사용 시 예외 처리한다.
- 보너스 번호 입력(1개)
  - 1부터 45 사이의 번호 1개를 입력받는다.
- 당첨 번호 파싱
  - 입력 문자열을 쉼표 기준으로 분리한다. 
  - 구분자가 존재하지 않거나 다른 구분자를 사용할 경우 예외 처리한다.
- 파싱 값 검증
  - 파싱된 번호 개수가 6개가 아니거나 중복될 경우 예외 처리한다.
  - 숫자가 아닌 값일 경우 예외 처리한다. 
- 보너스 번호 검증
  - 당첨 번호와 중복되거나 숫자가 아닌 값일 경우 예외 처리한다.
- 로또 발행
  - (구입 금액 / 1,000)장의 로또를 발행한다.
  - 각 로또는 1부터 45 사이의 서로 다른 번호 6개로 구성된다.
  - 발행된 로또 번호는 오름차순으로 정렬하여 표시한다.
- 로또 당첨 결과 계산
  - 각 로또와 일치하는 당첨 번호와 보너스 번호를 판단한다.
  - 일치하는 개수와 보너스 여부에 따라 등수를 결정한다.
  - 총 수익률을 계산한다.
- 당첨 내역 출력
  - 등수별 당첨 금액과 횟수를 출력한다.
  - 수익률을 소수점 둘째 자리에서 반올림해 출력한다.
- 예외 처리
  - 잘못된 입력 발생 시 "[ERROR] <메시지>" 형태로 출력한다.
  <br>예) [ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
  - 입력 단계로 되돌아가 재입력을 요구한다.
